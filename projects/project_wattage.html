MISSION PARAMETERS:

A Pokémon game controlled by how hard you ride. Live cycling data is fed directly into a Game Boy-inspired world, where power output determines what appears, how quickly the world moves, and how much damage you can inflict on increasingly unreasonable Pokémon.

SYSTEM ARCHITECTURE:

  • Input: BLE cycling power meter telemetry
  • Processing: Python with rolling power/cadence analysis
  • Game Engine: Pygame at a fixed 800×480 virtual resolution
  • Rendering: Custom Pokémon/GBA-inspired sprite and environment system
  • Replay: Recorded ride data can drive the game without live hardware

CONTROL PARAMETERS:

  • Power output controls Pokémon encounter rarity
  • Cadence and speed drive the cycling experience
  • Higher effort increases the probability of rare encounters
  • Boss encounters provide sustained high-power challenges
  • Power telemetry is visualized as a rolling in-game graph

FIELD SYSTEMS:

  • Scrolling terrain and animated Pokémon
  • Dynamic Pokémon encounters based on rider effort
  • Boss battles with power-based damage
  • FTP-relative power visualization
  • Ride replay using recorded telemetry
